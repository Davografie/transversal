# User Manual

How to play and run **Transversal**. This is the "how to use it" guide. For the rules in depth, see the [[Transversal Hub#📖 Game Design|Game Design]] docs; for how the software works under the hood, see the [[Transversal Hub#⚙️ Technical|Technical]] docs.

## Contents

1. [[Getting Started]] — join a session, claim a character, arrive at your first location
2. **Playing** — assemble a dice pool, roll, and read the outcome ([[Core Mechanics]], [[Dice Mechanics]])
3. **The interface** — character sheet, dice roller, [[Location Viewer]], SFX buttons
4. **Running the game (GM)** — [[GM Panel Development]], [[Relational Canvas]], locations and factions
5. **Authoring content (GM)** — [[SFX Authoring]] (and its lookup, [[SFX Reference]]), [[Roll Table and Life Path Authoring]]

## Quick reference

### Die ratings

| Die | Meaning |
|-----|---------|
| d4 | Poor |
| d6 | Average |
| d8 | Good |
| d10 | Great |
| d12 | Amazing |

### Simplified outcome (1–2 dice)

| Highest die | Outcome | Effect die |
|-------------|---------|------------|
| 1–2 | Fail | — |
| 3–5 | Marginal | d4 |
| 6–8 | Success | d6 |
| 9–11 | Exceptional | d8 |
| 12 | Perfect | d10 |

### Dice pool (3+ dice)

Roll, keep two dice for your **total**, and set aside one die as your **effect die**. See [[Dice Mechanics]] for the full procedure, hitches, and botches.
